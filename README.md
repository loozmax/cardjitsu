# Card-Jitsu

Оффлайн-порт Card-Jitsu из Club Penguin: PWA, играется в браузере
(в том числе на iPhone в горизонтальной ориентации, «На экран "Домой"»).

- `app/` — сама игра (статика, без сборки).
- `serve.py` — локальный дев-сервер: `python serve.py` → http://localhost:8080
  (отдаёт с `Cache-Control: no-cache`, чтобы браузер не залипал на старом JS).
- `test.js` — тесты движка: `node test.js`.

Боевая логика движка перенесена из реконструкции оригинального сервера
(solero/houdini): правила стихий, 18 power-карт, банк выигранных,
победные комбинации, Сэнсэй, прокачка поясов. Боевые анимации — оригинальные
SWF, проигрываются через Ruffle с рантайм-патчем цветов/поясов.
