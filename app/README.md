# Card-Jitsu — оффлайн для айфона

Полная карточная игра из Club Penguin: 509 карт, все 18 power-эффектов,
пояса, Сэнсэй, маска ниндзя. Работает в Safari как PWA, ландшафт, без интернета.
Только для личного пользования — не публикуй и не распространяй с чужим артом.

## Что здесь 1-в-1 оригинал

Боевая логика перенесена дословно из open-source эмулятора сервера CP —
[solero/houdini](https://github.com/solero/houdini) (MIT), файл
`houdini/handlers/games/ninja/card.py`:

- Стихии: огонь > снег, вода > огонь, снег > вода; при равной стихии — большее значение.
- Все 18 эффектов power-карт с точными таймингами: обмен значениями при равной
  стихии (1), ±2 на следующий раунд (2/3), сброс карты из банка соперника по
  стихии (4–6) и по цвету (7–12), запрет стихии на следующий раунд (13–15),
  замена стихии в текущем раунде (16–18). Эффекты «на победе» (2–15) срабатывают
  только если владелец карты выиграл раунд; 1/16/17/18 — при самой игре карты.
- Банк выигранных карт; победа: 3 карты одной стихии разных цветов ИЛИ по одной
  карте каждой стихии трёх разных цветов. Полностью заблокированная рука = поражение.
- Раздача: рука 5 карт, добор случайный из всей твоей коллекции (сыгранные
  карты возвращаются в пул — как в оригинале).
- Сэнсэй: до чёрного пояса тебе раздаются только карты без паверов, а он на
  каждую твою карту заранее держит бьющую — непобедим, ровно как в CP.
  С чёрным поясом он берёт случайные карты, и его можно победить (маска ниндзя).
- Прокачка: победа +5, поражение +1 (прогресс капает и за поражения), пороги
  поясов по формуле houdini: 5/15/30/50/75/105/140/180/225 опыта
  (белый → … → чёрный). Данные всех 509 карт — из `houdini.sql`.

Единственная правка к houdini: до чёрного пояса Сэнсэй не берёт контр-карты с
эффектами 1/16/17/18 — в эмуляторе такая карта изредка сама переворачивала
раунд против него, что противоречит оригиналу («Сэнсэй непобедим до чёрного пояса»).

## Что добавлено (в оригинале этого не было)

- **Бот-соперник** (`js/ai.js`) — в CP играли живые люди. Бой идёт строго по
  движку оригинала, бот лишь выбирает карту из руки. Сила растёт с твоим поясом.
- **Монеты и паки** (`CONFIG` в `js/engine.js`) — перенос кодов реального ККИ:
  пак = 5 случайных карт, минимум одна power-карта. Победа 30 🪙, поражение 5 🪙,
  Сэнсэй 100 🪙, пак 500 🪙. Меняй как хочешь.

## Запуск

```
cd app
python3 -m http.server 8080
```

На айфоне открой `http://<ip-компа>:8080`. Для установки на экран «Домой» и
оффлайна нужен HTTPS (service worker), самый простой приватный способ — Tailscale:

```
tailscale serve --bg 8080
```

Открой выданный `https://…ts.net` адрес в Safari → Поделиться →
**На экран «Домой»**. Дальше игра живёт как приложение и работает без сети.

Сейв в localStorage; в додзё есть Экспорт/Импорт (JSON) на случай чистки Safari.

## Арт и звук (кладёшь сам)

Игра полностью играбельна без ассетов — карты рисуются запасным видом
(цвет рамки = цвет карты, значение, стихия). Чтобы был родной арт:

1. Скачай SWF карточной игры из архивов CP (CP Archives / CPJourney и т.п.).
   Ищи раздел карточной игры — либо один SWF колоды со всеми картами внутри,
   либо отдельные SWF по id карты.
2. Извлеки картинки JPEXS-декомпилятором (ffdec) из командной строки:

   ```
   # один большой SWF:
   java -jar ffdec.jar -export image,sprite out/ Deck.swf

   # пачка отдельных SWF:
   for f in swfs/*.swf; do
     java -jar ffdec.jar -export image "out/$(basename "$f" .swf)" "$f"
   done
   ```

3. Переименуй арт карт в `assets/cards/<id>.png` (id — из `js/cards.js`;
   в коллекции внутри игры видно id/название/стихию/значение — сверяться удобно).
   Сопоставление арта с id — самая нудная часть, займёт около получаса;
   игра тем временем уже работает.
4. Опционально: `assets/ui/bg.png`, `assets/ui/sensei.png`; звуки
   `assets/sfx/{pick,round_win,round_lose,win,lose,pack}.mp3`.
5. Чтобы service worker закэшировал ВСЕ ассеты сразу (полный оффлайн до
   первого просмотра каждой карты), сгенерируй список:

   ```
   cd app
   python3 -c "import os,json;print(json.dumps([os.path.join(dp,f).replace('\\\\','/') for dp,_,fn in os.walk('assets') for f in fn]))" > assets/filelist.json
   ```

   и переоткрой страницу (или подними версию в `sw.js`).

## Структура

```
app/
  index.html            оболочка, регистрация SW
  style.css             ландшафтный UI
  manifest.webmanifest  PWA (landscape)
  sw.js                 оффлайн-кэш
  js/cards.js           база 509 карт (данные из houdini.sql, MIT)
  js/engine.js          движок боя/прокачки (зеркало houdini) + CONFIG
  js/ai.js              бот [добавка]
  js/ui.js              экраны: додзё, матч, Сэнсэй, магазин, коллекция
  assets/               твой арт и звук (опционально)
```

Тесты движка: `node test.js` из корня проекта (симуляции матчей, Сэнсэй,
все 18 паверов, пороги поясов, гарантия павера в паке).
